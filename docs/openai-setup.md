# Распознавание еды: ключ OpenAI и запуск

Распознавание работает через две серверные функции на Vercel:
- `/api/recognize`: фото + заметка → продукты, граммы, нутриенты (модель `gpt-5.4-mini`);
- `/api/transcribe`: голосовая заметка → текст (модель `gpt-transcribe`).

Обеим моделям нужен **один** ключ OpenAI.

## Где живёт ключ и почему это безопасно

- Ключ хранится **только** в переменных окружения Vercel, с пометкой Sensitive. После сохранения его не показывает даже дашборд Vercel.
- Ключ читают только серверные функции в папке `api/`. В приложение в браузере он не попадает. Сборка падает, если ключ случайно назвать `VITE_…` или `NEXT_PUBLIC_…` (такие переменные уходят в браузер).
- Функции отвечают только вошедшим пользователям. Каждый запрос проверяется по сессии Supabase, и считается дневной лимит: 50 распознаваний и 100 голосовых заметок на email в сутки, плюс общий потолок на всё приложение 500 и 1000. Лимит привязан к email и не обнуляется, если удалить аккаунт и зарегистрироваться заново.
- Фото и заметки нигде не сохраняются и не пишутся в логи. В OpenAI запросы уходят с `store: false`.

Чего с ключом **никогда** не делать: вставлять его в код, в файлы репозитория, в чат (в том числе со мной), в скриншоты. Если ключ куда-то утёк, сразу удали его в OpenAI (Revoke) и создай новый.

## 1. Отдельный проект и ключ в OpenAI

1. platform.openai.com → слева вверху переключатель проектов → **Create project** → `Calorie tracker`.
2. Внутри проекта: **Settings → Limits**.
   - **Model usage**: разреши только `gpt-5.4-mini` и `gpt-transcribe`.
   - **Budget**: месячный бюджет, например $10, и уведомление на почту.
3. **Billing** (на уровне организации): OpenAI списывает деньги с предоплаченного баланса. Держи **Auto recharge выключенным**. Тогда расход физически не превысит пополненную сумму.
4. **API keys → Create new secret key**:
   - Project: `Calorie tracker`
   - Permissions: **Restricted**, дальше по списку:
     - **Models** → `Read` (если такой пункт есть: список моделей);
     - **Model capabilities** → `Request`. Обязательно, именно это даёт право вызывать модели, в том числе `/v1/audio/transcriptions`. Выставь его **первым**: без него запросы падают с ошибкой `missing scope model.request`, даже если остальное включено;
     - **Responses API** → `Write` (если предлагается отдельно Read/Write, включи оба);
     - всё остальное (Assistants, Threads, Files, Vector stores, Fine-tuning, Batch, Evals, Realtime и т.д.) → `None`.
     
     Если после деплоя в Vercel → Logs видна ошибка `401` или `403` от OpenAI, значит, каких-то прав не хватает. Пришли мне эту строку.
   - Скопируй ключ. Он показывается один раз.

## 2. Положить ключ в Vercel

1. vercel.com → проект `calorie-tracker` → **Settings → Environment Variables → Add**.
2. Key: `OPENAI_API_KEY` (ровно так, **без** `VITE_` и `NEXT_PUBLIC_`).
3. Value: вставь ключ.
4. Environments: **Production** и **Preview**.
5. Включи **Sensitive** и нажми **Save**.
6. Переменные применяются только к новым деплоям: **Deployments** → последний → **⋯ → Redeploy**.

Адрес и публичный ключ Supabase у функций уже есть: их добавила интеграция Vercel ↔ Supabase.

## 3. Лимиты в Supabase

**SQL Editor** → вставь и запусти `supabase/migrations/20261005000000_ai_quota.sql`.

Скрипт создаёт счётчик вызовов и функцию `consume_ai_quota`. Без неё распознавание отвечает «Recognition isn’t set up yet». Лимиты меняются в этом же SQL (числа 50/100 на email и 500/1000 на приложение в начале функции), потом его нужно запустить заново. Сегодняшние счётчики при этом сохраняются.

## 4. Проверка

1. Открой приложение → **+** → сфотографируй тарелку или напиши «150 g rice, 120 g chicken breast» → **Recognize**.
2. На экране Review у каждого продукта видно, откуда взяты данные: `Label`, `Your library`, `Common values` или `AI estimate`, и откуда граммы: `your weight`, `≈ your weight`, `portion from photo`.
3. Микрофон: запиши заметку, она превратится в текст в поле заметки.

Если что-то не так, на экране ошибки под текстом мелко показан код причины и время, например `openai_timeout · 112 s`. Тот же код есть в Vercel → проект → **Logs** (без содержимого запросов). Что значат коды:

| Код | Что случилось | Что делать |
| --- | --- | --- |
| `openai_timeout` | Модель не ответила за 110 с (очень плотная этикетка, много фото) | Одно фото за раз; или поставить `OPENAI_REASONING=low` (по умолчанию и так `low`) |
| `http_504_timeout`, `client_timeout` | Функция Vercel или приложение перестали ждать | То же; проверить `maxDuration` в `vercel.json` (120) |
| `http_413_too_large`, `photos_too_large`, `request_too_large` | Фото не влезли в лимит запроса (4,5 МБ) | Меньше фото |
| `openai_400_…` | OpenAI отклонил запрос (схема, картинка) | Прислать код мне |
| `openai_401`, `openai_403` | Ключ без нужных прав или отозван | Раздел 1 выше |
| `openai_429_…`, `openai_insufficient_quota` | Лимит скорости или кончился баланс | Подождать или пополнить баланс |
| `no_food` | Модель не нашла еды (в тексте сообщения её объяснение) | Добавить заметку, что именно съедено |
| `daily_limit`, `app_daily_limit` | Дневная квота | Завтра, или поднять лимиты в SQL |
| `network_…` | Нет связи с сервером | Проверить интернет |

Переменные окружения функций (необязательные): `OPENAI_MODEL` (по умолчанию `gpt-5.4-mini`), `OPENAI_REASONING` (`low` по умолчанию; `medium` точнее на сложных этикетках, но медленнее и дороже), `OPENAI_TRANSCRIBE_MODEL`, `OPENAI_TRANSCRIBE_LANGUAGE` (язык голосовых заметок, по умолчанию `ru`), `OPENAI_WEB_SEARCH` (`off` выключает поиск КБЖУ в интернете), `OPENAI_SEARCH_MODEL` (модель для поиска, по умолчанию та же, что `OPENAI_MODEL`). Поиск в интернете OpenAI считает отдельно за каждый поисковый запрос; он делается только для продуктов без этикетки и без совпадения в библиотеке.

## Локальный запуск (необязательно)

Положи ключ в `.env.local` (файл в `.gitignore`, в git не попадёт):

```
OPENAI_API_KEY=sk-...
```

`npm run dev` поднимет и `/api/*` локально.

## Цена

`gpt-5.4-mini`: $0.75 за 1M входных токенов и $4.50 за 1M выходных. Распознавание с 1–2 фото обходится примерно в доли цента или пару центов. `gpt-transcribe` тарифицируется поминутно. Точные цены смотри на странице моделей OpenAI.
